      Test instructions & log format

      Enter one report per paragraph in the Google Doc or local log. Keep each ID unique. Edit a report using the same ID to correct it.

      T001 | 09:10 | A | 101 | PASS
T002 | 09:12 | A | 102,103 | PASS
T003 | 09:30 | A | 102 | WITHDRAWN
T004 | 11:00 | FINISH | 101 | FINISH

      To retract a report, replace its line with T004 | VOID. Deleting a line alone does not retract an accepted report. Lines beginning with # are comments.

      The test clock follows the latest valid report. The browser checks for updates every three seconds; the document is read every fifteen seconds.
